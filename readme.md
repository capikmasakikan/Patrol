# Security Patrol System

Full-stack web application for security patrol management with NFC tag scanning.

## Tech Stack

**Backend:**
- Java Spring Boot 3.2.1
- Spring Data JPA
- Spring Security + JWT
- MySQL Database
- Maven

**Frontend:**
- HTML5/CSS3/JavaScript
- Web NFC API
- Responsive Design

## Features

- ✅ Admin Dashboard
- ✅ Guard Management (CRUD)
- ✅ Checkpoint Management (CRUD)
- ✅ Real-time Patrol Tracking
- ✅ NFC Tag Scanning
- ✅ JWT Authentication
- ✅ Role-based Access Control
- ✅ Statistics & Reports
